Instale o agente leve no servidor

O agente é um programa pequeno (~2MB) que roda no servidor que você quer monitorar. Ele só lê uso de CPU, memória, disco e rede — nunca conteúdo de arquivo, senha ou comando digitado.

💻 Rode estes comandos no servidor a ser monitorado

Troque SEU-COLETOR pelo endereço do coletor OpenTelemetry do seu TracePilot. Pra esta demonstração, pode deixar localhost se o agente rodar na mesma máquina do coletor.

Não pode instalar nada nesse servidor? Também é possível a própria aplicação mandar os dados direto, sem instalar nada (ver a API de ingestão direta no repositório, pasta ingest/) — caminho alternativo, não coberto neste guia rápido.
